# App Portability Pack (Replit to Any Host)

This pack defines what “portable” means for your app, what you need to change (or enforce) to keep it portable, and the ongoing requirements to prevent portability regressions.

## What you get
- A clear portability definition (what “portable” means in practice)
- Technical requirements for run/build/config, data, background jobs, and deployment
- A “Definition of Done” checklist for portability readiness
- Ongoing governance so your app stays portable as it grows

## How to use this
1. Start with **00-PORTABILITY-OVERVIEW.md**
2. Use the **Definition of Done** checklist to plan the work
3. Implement the repo standards and CI checks so portability stays true
