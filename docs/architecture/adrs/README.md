# Architecture Decision Records (ADRs)

ADRs capture important architectural decisions and the reasoning behind them.

## When to Write an ADR

- A new major dependency or integration
- A significant architectural change
- A change that affects how teams work or deploy

## How to Write an ADR

1. Copy `ADR-TEMPLATE.md` and fill it in.
2. Number it sequentially (e.g., `ADR-0002-some-decision.md`).
3. Link it from this index.

## Index
